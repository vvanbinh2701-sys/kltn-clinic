# Clinic Management System - Web App Frontend

Feature-based Web Application built with **React**, **Vite**, **TypeScript**, **Ant Design**, **Zustand**, and **TanStack Query**.

## Key Features & Tech Stack
- **Framework**: React 18 + Vite
- **UI Library**: Ant Design (AntD)
- **State Management**: Zustand
- **Data Fetching & Cache**: TanStack Query (React Query)
- **Routing**: React Router v6
- **Realtime**: Socket.io Client
- **Printing Engine**: react-to-print (Thermal & A4 Prescriptions)
