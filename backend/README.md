# Clinic Management System - Backend Engine

Modular Monolith Backend built with **NestJS**, **TypeScript**, **PostgreSQL**, and **Redis**.

## Core Stack
- **Framework**: NestJS
- **Database**: PostgreSQL 15+ & Prisma ORM
- **Cache & Queue**: Redis & BullMQ
- **Realtime**: Socket.io
- **Security**: JWT, MFA/TOTP, RBAC, ABAC, AES-256-GCM Column Encryption, Cryptographic Hash Chain Audit Logs
