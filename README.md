# Clinic Management System (Quản lý Phòng khám / Bệnh viện)

Monorepo workspace containing:
- `frontend/`: React + Vite + TypeScript + AntD + Zustand + React Query (Feature-based Architecture)
- `backend/`: NestJS Modular Monolith + PostgreSQL + Redis + BullMQ
- `database/`: Database migrations, seeds, SQL views & procedures
- `infrastructure/`: Docker, Nginx, Redis & Monitoring configs
- `docs/`: Architectural documentation & Future AI Roadmap
